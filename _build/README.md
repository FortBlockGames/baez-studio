# baez.studio build

The site is plain static HTML served by GitHub Pages. Every page is generated by
`build.py` from the copy in `content.py`, so headings, pricing, FAQs and JSON-LD are
all in the raw HTML (no JavaScript needed to read them). Jekyll ignores this
`_build/` folder, so it is never published.

## Edit and rebuild

1. Change copy, prices or FAQs in `_build/content.py` (site-wide facts such as
   email, Cal.com link, Formspree endpoint and Vimeo id are in `SITE` at the top).
2. Run `python3 _build/build.py` from the repo root. It rewrites every
   `*/index.html`, `404.html` and `sitemap.xml`.
3. Commit and push to `main`; GitHub Pages deploys it.

`python3 _build/build.py --preview DIR` writes a copy with `index.html` links for
previewing outside a web server.

Styles: `assets/css/site.css` (design tokens on `:root`). Behaviour:
`assets/js/site.js` (progressive enhancement only).

## Pre-launch QA checklist

- [ ] Lighthouse (mobile): Performance ≥ 95, Accessibility 100, SEO 100
- [ ] Every page reads fully with JavaScript disabled (pricing, FAQ, tables)
- [ ] Google Rich Results Test passes for `/`, `/video-production/`,
      `/work/showreel-2026/`, `/locations/ann-arbor/`
- [ ] Cal.com calendar loads on `/` and `/book/`; Formspree form submits
- [ ] Showreel modal plays; no YouTube/Vimeo iframe loads before click
- [ ] No horizontal scroll at 390px width
- [ ] Swap Test: replace "Ann Arbor" with "Fort Wayne" on each city page and
      confirm the copy no longer makes sense (it is genuinely local)
- [ ] `robots.txt`, `sitemap.xml` and `llms.txt` return 200
- [ ] Search Console: resubmit the sitemap after launch
